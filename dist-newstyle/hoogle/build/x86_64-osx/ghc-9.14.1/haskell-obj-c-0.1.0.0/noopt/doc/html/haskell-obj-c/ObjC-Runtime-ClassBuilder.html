objc_allocateClassPair :: Class -> CString -> CSize -> IO Class Source #

Allocate a new class/metaclass pair. superclass is the superclass, name is the class name, and extraBytes is usually 0. Between this call and objc_registerClassPair, you may add ivars and methods.

objc_registerClassPair :: Class -> IO () Source #

Register a class pair previously created with objc_allocateClassPair. After registration, the class is ready to use.

objc_disposeClassPair :: Class -> IO () Source #

Destroy a class pair created with objc_allocateClassPair. Do not call this on classes that have existing instances.
