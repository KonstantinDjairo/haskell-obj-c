Description

Type-safe Objective-C message sending.

This module wraps the low-level libffi-based MsgSend API with a type-safe interface driven by the phantom type parameters on Selector. Each element in the selector's type-level argument list becomes a curried function parameter, and the return type is unmarshalled automatically.

-- Old style (manual libffi plumbing):
sendMsg obj sel (retPtr retVoid) [argPtr rawToken, argPtr rawSecret]

-- New style (type-safe, curried):
sendMessage obj sel token secret

Uses the varargs library (sequenceArgs) to lift monadic CPS brackets into variadic function argument positions, keeping all pointer-backed values alive until the FFI call completes.

Type-safe message sending

sendMessage :: forall (args :: [Type]) ret recv. (IsObjCObject recv, GatherObjCArgs args, ObjCReturn ret) => recv -> Selector args ret -> args :->: IO ret Source #

Send a message to an Objective-C object with type-safe argument unfolding.

The Selector phantom types drive the function signature: each type in the selector's argument list becomes a curried function parameter.

Uses retained semantics for object return values (suitable for property getters, factory methods returning autoreleased objects, and most other methods). For init/copy/new/mutableCopy methods, use sendOwnedMessage instead.

let sel = mkSelector "length" :: Selector '[] CULong
len <- sendMessage nsString sel

let sel2 = mkSelector "addProgressRangeFromStart:toEnd:"
        :: Selector '[CDouble, CDouble] ()
sendMessage activity sel2 0.0 0.5

sendOwnedMessage :: forall (args :: [Type]) ret recv. (IsObjCObject recv, GatherObjCArgs args, ObjCReturn ret) => recv -> Selector args ret -> args :->: IO ret Source #

Like sendMessage, but uses owned semantics for the return value.

Use for methods whose names start with init, copy, new, or mutableCopy — these return a +1 reference that the caller owns.

let sel = mkSelector "initWithString:"
       :: Selector '[Id NSString] (Id NSMutableString)
result <- sendOwnedMessage allocated sel str

Marshalling type classes

class ObjCArgument a where Source #

Types that can be marshalled as Objective-C message arguments.

The CPS style ensures that pointer-backed values (e.g., Id) remain alive for the duration of the FFI call via nested withForeignPtr brackets.

To add support for a custom type, provide an instance:

instance ObjCArgument MyStruct where
  withObjCArg s k = withStorableArg s k

class ObjCReturn a where Source #

Types that can be returned from Objective-C messages.

RawReturn is the intermediate type that libffi produces, which is then converted to the final Haskell type via fromRetained or fromOwned.

  • fromRetained — for most methods: retains the returned object (wraps a +0 / autoreleased reference).
  • fromOwned — for init/copy/new/mutableCopy methods: takes ownership of a +1 reference without an extra retain.

For non-object types both methods are identical.

data MsgSendVariant Source #

Which objc_msgSend variant to use for a given return type.

On ARM64 all three are identical, but on x86_64 floating-point and struct returns require dedicated trampolines.

class GatherObjCArgs (args :: [Type]) where Source #

Inductively gathers ObjCArgument values into a libffi Arg list, nesting CPS brackets so that every pointer-backed value remains alive when callFFI executes.

Uses sequenceArgs from varargs to lift the monadic CPS result back into a variadic function at each inductive step.
