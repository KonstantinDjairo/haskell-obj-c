Description

StablePtr-in-ivar infrastructure for Haskell-backed ObjC classes.

This module provides an alternative to the per-instance vtable approach in ObjC.Runtime.DynClass. Instead of allocating a C array of FunPtrs per instance, a single StablePtr to an arbitrary Haskell value is stored in the instance's _hs_vtable ivar.

IMP stubs (registered at class-creation time) read the StablePtr from self, deref it to recover the Haskell value, and dispatch directly — no foreign import ccall "dynamic" boundary crossing.

Used by ObjC.Runtime.ActionTarget, ObjC.Runtime.DelegateProxy, and (future) codegen'd delegate/subclass modules.

Ivar management

addHsDataIvar :: Class -> IO () Source #

Add the _hs_vtable ivar to a class being constructed.

Must be called between objc_allocateClassPair and objc_registerClassPair. The ivar is a single pointer that will hold a StablePtr (cast to Ptr ()).

writeHsData :: RawId -> StablePtr a -> IO () Source #

Store a StablePtr in an instance's ivar.

readHsData :: Ptr ObjCObject -> IO (StablePtr a) Source #

Read the StablePtr from an instance's ivar.

Takes a raw Ptr ObjCObject (as received by an IMP stub) to avoid wrapping in the hot dispatch path.

Dealloc handler

addStablePtrDeallocHandler :: Class -> IO () Source #

Register a dealloc method that frees the instance's StablePtr and calls [super dealloc].

Must be called between objc_allocateClassPair and objc_registerClassPair, after addHsDataIvar.
