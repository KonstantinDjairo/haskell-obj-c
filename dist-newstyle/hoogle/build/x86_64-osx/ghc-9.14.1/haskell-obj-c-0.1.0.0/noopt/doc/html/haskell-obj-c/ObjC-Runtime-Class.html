Obtaining class definitions

objc_getClass :: CString -> IO Class Source #

Look up a class by name. Returns nilClass if not found.

objc_getMetaClass :: CString -> IO Class Source #

Look up a metaclass by name.

objc_lookUpClass :: CString -> IO Class Source #

Look up a class by name. Unlike objc_getClass, does not call the class handler callback if the class is not found.

objc_getRequiredClass :: CString -> IO Class Source #

Like objc_getClass but aborts the process if the class is not found.

objc_getClassList :: Ptr Class -> CInt -> IO CInt Source #

Get the total number of registered classes and optionally fill a buffer.

objc_copyClassList :: Ptr CUInt -> IO (Ptr Class) Source #

Copy the list of all registered classes. The returned array must be freed with free. The count is written to the output parameter.

Instance variables
