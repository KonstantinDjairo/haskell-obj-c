Description

Dynamic Objective-C message sending via libffi.

On ARM64, objc_msgSend is a trampoline whose calling convention must match the target method exactly. We use libffi to construct the correct call frame at runtime, given the argument and return types.

Usage example (sending length to an NSString):

len <- sendMsg nsString lengthSel (retCULong) []
