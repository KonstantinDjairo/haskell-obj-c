ObjC.Runtime.Framework

Description

Dynamic framework loading via dlopen.

Use this to load macOS frameworks at runtime that are not linked at compile time, making their Objective-C classes available to objc_getClass and the rest of the runtime.

Synopsis
  • loadFramework :: String -> IO ()
  • loadFrameworkAt :: String -> IO ()

Documentation

loadFramework :: String -> IO () Source #

Load a macOS framework by name. Looks for it in /System/Library/Frameworks/<name>.framework/<name>.

Throws an IOError if loading fails.

After loading, all Objective-C classes defined by the framework become available to objc_getClass and friends.

loadFrameworkAt :: String -> IO () Source #

Load a framework (or any dynamic library) by full path.

Throws an IOError if loading fails.
