Object lifecycle

alloc :: IsObjCObject (Id a) => IO (Id a) Source #

Send +[Class alloc] and return an unmanaged, typed Id.

The returned object has no finalizer — it must be passed to an init method (which returns a properly managed Id).

The class is determined by the return type via staticClass. Use with TypeApplications when the return type is ambiguous:

obj <- alloc @NSWindow

objcInit :: IsObjCObject (Id a) => Id a -> IO (Id a) Source #

Send -[obj init] — the plain NSObject initializer.

Returns a properly managed Id with a release finalizer (the init result is a +1 owned reference).

The input object (typically from alloc) may differ from the output due to class clusters; always use the returned value.

new :: IsObjCObject (Id a) => IO (Id a) Source #

\[\[Class alloc\] init] — allocate and default-initialize.

Equivalent to ObjC's +new. The class is inferred from the return type:

menuItem <- new @NSMenuItem
